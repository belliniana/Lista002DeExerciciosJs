# Lista de Exercícios 02 - Arrow Functions (JavaScript ES6+)

Este projeto contém uma coleção de exercícios práticos em JavaScript com foco em Arrow Functions, métodos de array e lógica de programação moderna.

---

## Objetivo

Praticar e dominar:

- Sintaxe de Arrow Functions (=>)
- Retorno implícito
- Métodos de array (map, filter, find, reduce, some, every)
- Funções de alta ordem (HOF)
- Closures e lógica funcional

---

## Níveis dos Exercícios

### Fácil
Foco na sintaxe básica de arrow functions e retorno de valores simples.

### Médio
Uso de métodos de array como map, filter, find, reduce, some e every.

### Difícil
Conceitos avançados como:
- Encadeamento de métodos
- Funções que retornam funções (closures)
- Manipulação de objetos
- Simulação de contexto (this)
